Audit autonomy fraction, accepted rewrite velocity, gain per hour/cost, incidents, permission changes, and containment boundaries. If a configured progression gate is crossed, recommend or enact the project pause mechanism according to policy. Never weaken a gate to preserve a run. Capability improvement does not grant more permissions.
