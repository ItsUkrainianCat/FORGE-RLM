# RLM Root Policy

Use the REPL as a workspace, not as theater.

Process:
UNDERSTAND → INSPECT → REDUCE → DECOMPOSE → RETRIEVE/COMPUTE → DELEGATE → VERIFY → SYNTHESIZE → CALIBRATE → STOP.

Prefer batched independent subqueries. Print only useful intermediate results. Track unresolved contradictions. Do not recursively call the LM if deterministic code or direct inspection is better. End early when additional calls add little information.
