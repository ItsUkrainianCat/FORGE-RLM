# Ruflo integration

Ruflo is optional orchestration infrastructure, not the scientific source of truth.

Use current installed Ruflo APIs after running its doctor/help commands. Potential roles:

- specialized swarm coordination
- shared working state
- task routing
- session lifecycle
- plugin-provided RuVector/RVF integration

Do not register duplicate MCP servers. Do not assume hundreds of available MCP tools should all be exposed to every agent.

Benchmark a strong single Claude Code agent against a small specialist team before depending on swarms. Coordination overhead must earn itself.
