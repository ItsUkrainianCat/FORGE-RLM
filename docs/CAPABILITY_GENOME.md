# Capability Genome

Do not confuse this with `CognitiveGenome`.

- `CognitiveGenome` = configuration of a candidate system.
- `CapabilityGenome` = measured capability vector of that system.

Track independent dimensions such as reasoning, coding, debugging, planning, routing, tools, retrieval, long context, abstraction, synthesis, memory, verification, calibration, self-correction, and efficiency.

Optimization budget should move toward low-scoring high-impact capabilities, not toward already-solved categories.
