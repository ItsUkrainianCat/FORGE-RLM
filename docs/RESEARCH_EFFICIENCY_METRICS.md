# Research-efficiency metrics

The AIDE component optimizes the efficiency of AI R&D, not merely endpoint task score.

Track:

- endpoint private grade;
- gain per candidate evaluated;
- gain per model call;
- gain per token/cost unit;
- gain per wall-clock hour;
- steps/cost to threshold;
- candidate crash rate;
- accepted rewrite rate;
- external generalization delta;
- reward-hacking rate;
- variance across seeds;
- prompt/context size over run progress;
- duplicate-experiment rate;
- human-intervention frequency.

Every project-SOTA claim must specify its budget. A system that gets a slightly higher score with radically more compute may be a valid MAX_QUALITY point on the Pareto frontier, but it is not automatically a better research agent.
