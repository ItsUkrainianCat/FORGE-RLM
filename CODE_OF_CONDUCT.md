# Community code of conduct

Be respectful, specific, and evidence-minded. Welcome contributors of all backgrounds and experience levels. Critique ideas and experiments without personal attacks; acknowledge uncertainty and give credit for others' work.

Harassment, discriminatory abuse, threats, doxxing, sexual harassment, and intentional disclosure of private information are unacceptable in project issues, pull requests, discussions, and other project spaces.

Maintainers may edit or remove harmful content, close discussions, or restrict participation. Responses should be proportionate to the behavior. Report concerns privately using a contact method listed on the maintainer's public GitHub profile; avoid publishing personal details. If no private contact is listed, request a private channel without sharing the incident details publicly.

This is a project-specific policy; it does not claim affiliation with an external code-of-conduct organization.
