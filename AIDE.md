# AIDE component

`forge/aide/` is FORGE's controlled self-evolving AI R&D subsystem.

It is **AIDE-inspired**, not the Weco AIDE2 codebase.

Core contract:

```text
inner task optimization uses public feedback
outer harness selection uses sealed private grades
accepted changes become the next incumbent
budgets stay comparable
noise/reward-hacking/generalization are gated
outer-driver replacement requires ignition + approval
permissions/governance/holdouts are not self-modifiable
```

Start with `docs/AIDE_QUICKSTART.md` and `docs/AIDE_RSI_DESIGN.md`.
